# 全周期考级匹配

近期目标是规划周期中的优先节点，达到该节点后继续计算GESP后续场次。期望月份可留空；填写后用于提醒是否按时达成，不阻止更早推荐。只有老师明确指定的场次固定时间。

## 推算依据

- 常规课按每周一课逐课推进，寒暑假照常，既有复习与测评不再加周。
- 每年3、6、9、12月为候选场次。官方日期优先；未公布时只展示月份，并只计算该月开始前学过的课。若规划只覆盖该月的一部分且日期未知，则保留待定，不认定考试落在周期内。
- 从学生实际已通过等级的下一级逐级匹配，每场最多一个等级。报考资格仍需核对，不根据教学进度推断跨级资格。
- 具体课次及集训逐日主题对应见 `data/standards/gesp/course-mapping.json`。每组条件都需满足，组内可选等价教学来源。复习和测评不能替代首次知识教学。主干课次满足是拟安排时间的依据；补充项未完成时不能认定已覆盖完整考纲。
- 课程名称或考纲正文变更后，受影响的对应关系失效，需重新核对。课程对应表可在“课程与目标 → GESP / CSP目标”查看。
- 集训仅计入考试前已经安排的具体教学日。拟参加集训会保留依赖说明，常规课不因重复内容跳课。
- 后续考级以前一级按计划完成、补齐知识、测评及资格确认作为条件，不修改学生已通过记录。

## 使用与调整

1. 生成时建立整个周期的常规课、集训、考级候选和推荐理由。
2. 在“全周期考级匹配依据”查看每场建议、未安排原因及待补项；家长版展示拟参加节点和阶段补充要求。
3. 老师修改的阶段及详解会保留。在“老师调整考级场次”指定月份、填写能力巩固等安排说明，然后点击“应用考级调整并重新匹配路线”。指定的前级场次会约束后级时间；选择“按系统推荐”可解除指定。仅修改考级文案不固定场次。删除一个自动推荐节点后，重算不会在相同月份恢复该级，可顺延至后续场次。
4. 学生实际通过等级、进度或集训条件变更后，重新匹配草稿。手工调整常规阶段日期不会自动改写逐课日历，须核对周课衔接。
5. 考级安排变更但未重算时，草稿可保存，预览、定稿和导出需先完成重新匹配。前后级倒序、同场或中间等级无法衔接时给出明确提示，老师可调整场次后重试。旧草稿点击“重新匹配考级与路线”启用新规则；仅更新资料不重排路线。历史定稿继续保留原有目标、日期和资料。

## 认证日历来源

- 季度月份：[GESP官方常见问题](https://gesp.ccf.org.cn/101/1002/10027.html)。
- 2026年12月26日：[第16次认证报名通知](https://gesp.ccf.org.cn/101/1002/10305.html)，2026-10-22核对。
- 后续官方日期由管理员在“课程与目标 → 认证日历”维护，保存后用于新规划或重新匹配；不在请求中临时猜测日期。

本功能依据已归档的用户提供版C++认证大纲和当前课程主题，仍需补充课程教学细节、测评和实际考试成绩。CSP近期节点单独保留，不套用GESP季度日历。
