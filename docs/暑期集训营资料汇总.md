- 新安装使用已补齐的12个冬夏营课程库；已有本机资料库重启时升级，升级前备份原资料库到 `app/.data/backups/library-before-summer-2026-10-22.json`。

- 新大纲改变教学安排或默认入营条件时，重新标记为待核对；资料转录完成不等于已确认个人入营条件。
- 历史定稿保留当时的课程快照。旧草稿如需引用新版资料，在调整路线页点击“更新课程资料”。

- 原图中的年龄描述、奖项目标是营地招生与课程目标说明，不作为官方报名规则或通过承诺。XP02 与 NOIP 没有列出年龄下限，不补设年龄限制。
- 六个 XP 营均为10天，DAY10只列上午；不补写下午或晚上的内容。NOIP 为20天日程，DAY07、DAY14为休息日，共18天有课程安排；排期保留休息日，常规周课照常。
